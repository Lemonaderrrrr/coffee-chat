# 部署说明

预约页 `book/` 和管理面板 `admin/` 共用这一个后端：一张 Google 表格加一个 Apps Script。全程大约 15 分钟。

## 1. 建表格和脚本

1. 用 **UCI Google 账号**登录，新建一张 Google 表格，名字随意（比如 Outreach）。
2. 菜单 **扩展程序 → Apps Script**。
3. 左侧齿轮 **项目设置** → 勾选 **在编辑器中显示 "appsscript.json" 清单文件**。
4. 回到编辑器：
   - 把 `backend/Code.gs` 的全部内容贴进 `Code.gs`，覆盖原有内容。
   - 把 `backend/appsscript.json` 的全部内容贴进 `appsscript.json`，覆盖原有内容。
   - 保存。
5. 左侧齿轮 **项目设置** → 最下面 **脚本属性** → 添加一个属性：名称 `SHEET_ID`，值是表格网址里 `/d/` 和 `/edit` 之间那一串。保存。
   （如果你是从表格菜单"扩展程序 → Apps Script"打开的，脚本已经绑定在表格上，这一步可以跳过；加上也没坏处。）
6. 顶部函数下拉框选 **setup**，点 **运行**。
   - 第一次会要授权：表格、日历、以 Web 应用运行。全部允许。
   - 运行完打开 **执行日志**，复制 `Admin key: ...` 后面那串。这是管理面板的密钥，只自己留着。

## 2. 部署成 Web 应用

1. 右上角 **部署 → 新部署**，类型选 **Web 应用**。
2. **执行身份**：我。**有权访问的用户**：任何人。
3. 点部署，复制以 `/exec` 结尾的网址。

**如果"有权访问的用户"里没有"任何人"**，只有"加州大学尔湾分校内的任何人"：说明学校的 Google 账号不允许校外访问。用这个设置，教授必须在浏览器里登录 UCI 账号才能订，不可靠。这时换成**个人 Gmail**，从第 1 节第 1 步重来。代码不用改。

## 3. 测一下能不能从外面访问

开一个无痕窗口（不登录任何 Google 账号），访问：

```
<你的 /exec 网址>?action=ping
```

看到 `{"ok":true,...}` 就说明校外也能用。看到 Google 登录页或报错，就按上一节换个人 Gmail。

## 4. 把网址填进页面

`book/index.html` 和 `admin/index.html` 顶部各有一行：

```js
API_URL: "",
```

把 `/exec` 网址填进去，两处一样。没填的时候两个页面都显示预览数据，不会真的订。

这一步和推送到 GitHub 由 Claude 做，推送前会先问你。

## 5. 导入联系人

1. 打开 https://lemonaderrrrr.github.io/coffee-chat/admin/ ，输入第 1 节复制的密钥。
2. **导入** 标签 → 选本机的 `outputs/build/outreach-seed.json`（41 个联系人，不在仓库里）→ 导入。

## 6. 补几项信息

- **办公室**：给打算约见面的教授填上房间号。预约页的"Your office"会显示它。
- **校内咖啡店**：在 **可约时段 → 预约设置** 里一行填一个。不填的话，页面写"Leon 会推荐离你近的地方"。
- **可约时段**：默认周一、三、五下午 1–5 点。在 **可约时段** 标签里改。页面会自动避开你 Google 日历上已有的安排，全天事件不算。

## 7. 日常怎么用

| 什么时候 | 做什么 |
|---|---|
| 发完首封 | 面板里点"今天发了首封"：阶段变成已发，10 天后提醒跟进 |
| 对方回复愿意见面 | 点"复制预约链接"，用模板 S1 发给对方 |
| 对方订好时间 | 你和对方都收到日历邀请；面板上自动变成已约 |
| 见完面 | 点"见过面了"：4 天后提醒你发 K2 |

也可以直接告诉 Claude，它用 `outputs/build/outreach.py` 改。要它能改，在 `outputs/build/.outreach.env` 里写两行：

```
API_URL=<你的 /exec 网址>
ADMIN_KEY=<第 1 节的密钥>
```

这个文件只在你电脑上，`.gitignore` 已经挡住，不会被提交。

## 8. 改了代码之后

Apps Script 里 **部署 → 管理部署 → 编辑（铅笔图标）→ 版本选"新版本" → 部署**。网址不变，页面不用改。

## 9. 本地测试

```bash
node dev/test.js
```

```bash
node dev/server.js
```

第一条跑后端的 17 项测试。第二条在 http://localhost:8787 起一个本地预览，管理密钥是 `dev-key`，数据在内存里，重启就清空，不连 Google。

## 安全

- 管理密钥只在 Apps Script 的脚本属性和你的浏览器里。不要发给别人，也不要写进仓库。要换的话，在 **项目设置 → 脚本属性** 里改 `ADMIN_KEY`。
- 联系人数据只在 Google 表格里。仓库是公开的，联系人文件和密钥文件都被 `.gitignore` 挡住了。
- 每个预约链接带 20 位随机码，别人猜不到。但链接被转发后，拿到的人可以用它订时间。
